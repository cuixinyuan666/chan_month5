## CHAN_RUST Flutter UI 优化评估（咨询，未改动代码）
- 现状：桌面端（window_manager 隐藏标题栏）缠论 K 线工具；图表 CustomPainter 全量手绘。
- 配色已专业自洽：K0~Kn 连线分层色（琥珀/玫红/翠绿/紫/青/橙）、Normal/OverSeg 中枢双色系、三类买卖点 6 色（买红/卖绿按类分色阶）、红涨绿跌。tooltip 用 Consolas 等宽（数字对齐好）。
- 最大短板=可发现性：核心操作全藏在左/中/右鼠标热区（点击步进/播放/前进、长按复位/重载/跑完）+ 双击十字线 + 键盘方向键，界面无任何可见标记；主/副图指标 chip 默认透明度仅 0.38。
- 次要短板：背景纯 #121212 平、无记忆点；中文 UI 未显式配置字体（依赖引擎回退，方块风险）；错误态是浮动橙字易被遮挡；十字线态每次 setState 全量重建 BarFeatureLookup + asOf 合并框（性能可优化）。
- 建议优先级：P0 常驻播放控制条+首次引导+手势提示胶囊；P1 层级状态条(记忆点)+中文字体配对+标题栏信息；P2 错误固定栏+设置分组+加载遮罩；P3 缓存 featureLookup/asOf、CustomPainter shouldRepaint、仅 debug 记 building runtime。
