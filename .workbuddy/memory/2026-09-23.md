    取最大者加左右 padding → 内容宽。

    `contentW = _measureContentWidth().clamp(240, 屏宽-边距*2)`。
    既保留「宽度随最长指标名自适应、不占满整屏」，又让 ListView 拿到确定高度。
  - 标题宽改用真实 `widget.title`（原来写死 '主图指标'，副图也能量准）。

### 通用教训（Flutter，重要）
- **条件包裹丢 State**：在「直接返回 child」与「包一层 Row/LayoutBuilder 等」之间切换，
  会把 child 的 Element/State 整体重建（无 GlobalKey 时）。修法两种：
  ① 让包裹结构恒存在、用 `Offstage`/`Visibility`(maintainState) 控显隐；
  ② 给 child 挂 GlobalKey（重 parenting 保状态，但成本与坑更多，首选 ①）。
- `Offstage` offstage=true 时自身 size=constraints.smallest（Row 里占 0 宽），
  子树仍会 build 但不 paint/不命中，适合"结构恒定+显隐切换"。
