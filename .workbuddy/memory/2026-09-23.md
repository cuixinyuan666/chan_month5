## 00:52 修复重大BUG：点「下拉」只变暗、指标选择面板不显示（上一条改动引入的回归）

- 现象：点主/副图指标下拉钮，K 线图整体变暗（0x99000000 遮罩弹出），但面板本身不出现 → 选不了指标。
- 根因：上一条「自适应宽度」把 `SizedBox(确定宽高)` 换成 `ConstrainedBox + IntrinsicWidth`。
  `SizedBox` 给 Column **确定高度**，Expanded(ListView) 才有界高度可画；
  `IntrinsicWidth` 走**固有尺寸测量**，而 ListView 是可滚动控件、无固有宽度/高度，
  Expanded 在固有测量阶段拿不到高度 → 面板塌陷（只剩遮罩）。
  **结论：`IntrinsicWidth` + `Column` + `Expanded(ListView)` 是死对头，永远别这么套。**

  - 去掉 IntrinsicWidth。
  - 新增 `_measureContentWidth()`：用 TextPainter 量「标题 / 各指标名+取值 / 各类别头」文字宽，
    取最大者加左右 padding → 内容宽。
  - 面板回到**确定尺寸**：`BoxConstraints(minWidth:contentW, maxWidth:contentW, maxHeight:maxH)`，
    `contentW = _measureContentWidth().clamp(240, 屏宽-边距*2)`。
    既保留「宽度随最长指标名自适应、不占满整屏」，又让 ListView 拿到确定高度。
  - 标题宽改用真实 `widget.title`（原来写死 '主图指标'，副图也能量准）。

### 通用教训（Flutter，重要）
- **条件包裹丢 State**：在「直接返回 child」与「包一层 Row/LayoutBuilder 等」之间切换，
  会把 child 的 Element/State 整体重建（无 GlobalKey 时）。修法两种：
  ① 让包裹结构恒存在、用 `Offstage`/`Visibility`(maintainState) 控显隐；
  ② 给 child 挂 GlobalKey（重 parenting 保状态，但成本与坑更多，首选 ①）。
- `Offstage` offstage=true 时自身 size=constraints.smallest（Row 里占 0 宽），
  子树仍会 build 但不 paint/不命中，适合"结构恒定+显隐切换"。
