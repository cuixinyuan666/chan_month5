# 设计：K0中枢 + 中枢命名纠偏 + 单段更早虚框

日期：2026-07-27  
状态：规格已通过，进入实现

## 背景

1. **Kn 连线**来自 **K(n-1)** 高低点连线；内部 `level=1` 的段是 **K1（=K0连线）**。
2. 当前主图「K0中枢」实际由 **K1 段**构成，应标为 **K1中枢**。
3. 需要新增真正的 **K0中枢**：由 **K0 合并框实体**构成。
4. 当前须等第 3 个 Kn **确认**才出第一框；应允许 **单 Kn / 含进行中** 更早出 **虚框**。

## 决策摘要（已确认）

| # | 决策 |
|---|---|
| 1 | 方案：命名纠偏 + 新增 K0 层 + 展示轨单段雏形（非全局 `one_bi_zs`） |
| 2 | K0中枢构成 = **合并后的 K0 实体**（`KlineCombineFrame`），不用未合并 1 分钟 K |
| 3 | 第一次虚框：允许 **单 Kn** 即出（单段雏形，`is_sure=false`） |
| 4 | 买卖点与中枢 **同号同名** 一起改 |
| 5 | 连线/合并展示名 **不改**（仍 `K(n-1)连线/合并`） |
| 6 | 不恢复 Auto / 跨段中枢；不回写永久结构；无未来 |

## 1. 命名

| 内部 level | 构成元素 | 连线/合并（不变） | 中枢/买卖点（新） |
|---|---|---|---|
| K0 合并实体（新层） | K0 合并框 | — | **K0中枢 / K0买卖点** |
| 1 | K1（=K0连线） | K0连线 / K0合并 | **K1中枢 / K1买卖点** |
| 2 | K2（=K1连线） | K1连线 / K1合并 | **K2中枢 / K2买卖点** |
| n | Kn | K(n-1)连线/合并 | **Kn中枢 / Kn买卖点** |

## 2. K0中枢数据与计算

- 输入：K0合并框；末框=构建中
- 映射伪 LevelSegment 后复用 find_zs / ZSIncEngine；Normal/OverSeg 双算
- JSON：`zs_k0_normal_frames` / `zs_k0_over_seg_frames` / `bsp_k0_*`
- as-of：`x2<=asOf`；不回写

## 3. 单段更早虚框

- 展示输入 = 冻结段 + 至多 1 个进行中
- ≥1 段可出虚框；双离开闭合改实线
- 单段仅展示轨；不全局 one_bi_zs

## 4. 买卖点

- 与中枢同号改名；K0买卖点吃 K0中枢；算法不改

## 5. 边界

- 不改连线/合并名；不恢复 Auto；不用未合并 1 分钟 K

## 6. 验收

1. 真 K0中枢；原 K0中枢→K1中枢
2. 第一个 Kn/K0合并框即可虚框
3. 双离开→实线；关虚线开关→全实线
