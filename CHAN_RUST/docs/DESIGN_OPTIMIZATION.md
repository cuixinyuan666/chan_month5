# CHAN_RUST · K线 App 设计优化方案（UI Design System）

> 评估对象：`CHAN_RUST/flutter/chan_kline`（桌面端 Flutter，暗色主题，缠论逐 K 回放工具）
> 评估角色：UI Designer（界面设计系统 / 组件库 / 可访问性）
> 日期：2026-07-28
> 状态：**提案（规划阶段）** —— 尚未改动任何工程代码，仅产出设计规范与可视化样张，待确认后落地。

---

## 0. 一句话结论

当前 App 的**图表内核（缠论分层连线 / 中枢 / 买卖点）配色语义清晰、层次分明，是合格的量化可视化**；但**外围界面（标题栏、设置面板、指标芯片、十字线信息框、空/错/加载态）缺乏统一设计语言**：颜色全是散落的十六进制字面量（全工程 11 个文件共 **94 处** `Color(0x…)`），没有令牌（token）体系、没有排版/间距/圆角/层级规范、字号与透明度随手写、无障碍基本关闭。

**优化方向不是重画图表，而是：① 建立设计令牌 + 暗色主题，② 把外围界面收敛成一致的组件系统，③ 补齐状态/无障碍/可发现性。** 图表语义色直接沿用现有 `ChartLevelLineStyle` 的调色板（它本身就是范例）。

---

## 1. 现状审计（Audit）

### 1.1 颜色系统（最严重）
| 问题 | 证据 |
|---|---|
| 无集中令牌，颜色字面量散落 | `main.dart`(7)、`kline_chart.dart`(30)、`chart_level_line_style.dart`(25)、`edge_control_panel.dart`、`indicator_picker_chip.dart`、`crosshair_tooltip_panel.dart`、`*_indicator_picker.dart`、`fractal_confirm_paint.dart`、`test_ohlc_editor_dialog.dart`、`msg_history.dart` 共 **94 处** |
| 表面色不成体系 | 画布 `0xFF121212`、面板 `0xF01A1A1A`、芯片 `0xCC1A1A1A`、tooltip `0xEE121212` —— 同为"深灰"却 4 种不同 alpha，无层级梯度 |
| 主题没真正生效 | `MaterialApp` 用 `ColorScheme.fromSeed(0xFF42A5F5)`，但所有自定义控件都用裸色，seed 主题被架空 |
| 语义色仅图表有 | 分层连线/中枢/买卖点的色系很专业；但面板/芯片/按钮没有语义色（成功/警告/危险/信息） |

### 1.2 排版（Typography）
- 绝大多数文字用默认系统字体；唯独 tooltip 用 `Consolas` 等宽 —— 没有统一字体策略。
- 字号随手写：`11 / 12 / 13 / 18` 无标度；行高 `1 / 1.1 / 1.35` 无规范。
- 无字重/字阶定义，标题与正文无视觉差异（设置面板标题仅 `w600` 一处）。

### 1.3 间距与布局（Spacing）
- `SizedBox(height: 8/10/12)`、`padding: 4/8/10/12` 随意组合，无 4 的倍数标度。
- 设置面板是"一长条控件"平铺：股票下拉 → 周期 → 起止时间 → 两个 Switch → 三个按钮，**无分组、无层级、无留白节奏**。

### 1.4 组件（Components）
| 组件 | 现状 | 问题 |
|---|---|---|
| 指标芯片 | 默认透明度 `0.38`，hover 才 `1.0`；多个指标用 `/` 分隔挤一行 | 可读性差、可发现性低（静默隐藏）；多选时难以解析 |
| 十字线信息框 | `0xEE121212` 半透明 + 1px 描边，等宽两列 | 可用，但无语义强调、无层级分区、分隔用 `=` 铺满略显粗糙 |
| 设置面板 | `Material elevation:8` + 裸色，标题行 36px | 与图表视觉割裂，无分区 |
| 窗口控件 | `WindowCaptionButton` 默认样式 | 与自定义设计语言不统一 |
| 标题栏 | 透明 36px，设置按钮 + 三键 | 设置入口与图表左上指标芯片区"开孔穿透"靠硬编码 280px 对齐，脆弱 |

### 1.5 状态与无障碍（States & A11y）
- **空态**：`Text('暂无 K 线…')` 居中裸文本；**错误**：左上角橙色裸 `Text`；**加载**：右上角小 spinner —— 均无设计打磨。
- `Windows` 端 `ExcludeSemantics` 直接关掉读屏；固定字号不随系统缩放；无 focus ring 规范；触控目标仅有图标按钮 36px（达标但无统一规范）。

### 1.6 亮点（保留，不要动）
- `ChartLevelLineStyle` 的分层/中枢/BSP 调色板 —— **语义清晰、层次分明，是全局配色的范本**，应直接提升为设计令牌源。
- 图表交互（逐 K 步进、十字线三态、左中右热区、键盘连发）—— 专业且高效。
- 面板"贴边吸附 + 遮罩关闭"—— 交互模式好。

## 2. 设计系统提案（Design Tokens）

> 落地方式：新建 `lib/theme/chan_theme.dart`（含 `ChanColors` / `ChanTypography` / `ChanSpacing` / `ChanRadius` / `ChanElevation` 常量 + `chanDarkTheme()`），全工程引用，消灭裸色字面量。

### 2.1 颜色令牌（暗色，统一表面梯度）
| Token | 值 | 用途 |
|---|---|---|
| `bgBase` | `#0E1116` | 画布/窗口底色（替代 121212，更中性冷调） |
| `bgSurface` | `#161B22` | 面板/卡片底 |
| `bgSurfaceRaised` | `#1C2230` | 芯片/输入/悬浮层 |
| `bgElevated` | `#222B3D` | Popover/菜单 |
| `borderSubtle` | `rgba(255,255,255,.08)` | 内描边 |
| `border` | `rgba(255,255,255,.12)` | 卡片/分区描边 |
| `textPrimary` | `#E6EDF3` | 主文字（统一替代散落的 E2E8F0） |
| `textSecondary` | `#9DA7B3` | 次级文字/标签 |
| `textMuted` | `#6B7585` | 占位/禁用 |
| `accent` | `#4C9AFF` | 主操作/设置/聚焦（替代 seed 42A5F5，更克制） |
| `accentSoft` | `rgba(76,154,255,.16)` | 选中底/高亮 |
| `danger / warning / success` | `#F0616D / #E5A03B / #3FB950` | 错误/警告/成功语义 |

**图表语义色（直接接管 `ChartLevelLineStyle` 现有值，列入令牌，不再裸写）：**
- 分层连线 K1–K6：`琥珀 #F59E0B / 玫红 #EC4899 / 翠绿 #10B981 / 紫 #8B5CF6 / 青 #06B6D4 / 橙 #F97316`
- 中枢 Normal：`玫红 #E11D48 / 青 #0D9488 / 靛 #4F46E5 / 橙 #EA580C / 粉 #DB2777 / 黄绿 #A3E635`
- 中枢 OverSeg：`蓝 #3B82F6 / 青 #06B6D4 / 靛紫 #6366F1 / 青绿 #14B8A6 / 天蓝 #0EA5E9 / 亮青 #22D3EE`
- 买卖点：买 `红 #E53935 / 橙红 #FB8C00 / 黄 #FDD835`；卖 `绿 #43A047 / 青 #00ACC1 / 紫 #8E24AA`

### 2.2 排版令牌
```
fontFamily:      'Inter'（UI） / 'JetBrains Mono'（数值/代码，统一替代 Consolas）
scale:  11 / 12 / 13 / 14 / 16 / 20 / 24
weight: 400 / 500 / 600 / 700
lineHeight: 1.2（紧凑） / 1.4（正文） / 1.5（多行）
```
- 建立"标签 / 控件值 / 标题 / 分区标题"四类标准 TextStyle，全工程复用。

### 2.3 间距 / 圆角 / 层级
```
spacing(4 基准): 4 / 8 / 12 / 16 / 20 / 24 / 32
radius: 4(控件) / 6(芯片) / 8(卡片) / 12(面板)
elevation: 面板 0+描边 / Popover 8 / 菜单 12（暗色下以描边为主、阴影为辅）
```

### 2.4 组件改造要点
| 组件 | 优化 |
|---|---|
| **指标芯片** | 改为"胶囊组"：每选中一项一个带细描边的 pill，左侧色点（对应层类型语义色），默认透明度提到 `0.85`（可发现），hover `1.0` + 微抬升；下拉箭头独立按钮；双击 pill 关闭 |
| **设置面板** | 分区：① 数据（股票/周期/起止/截断开关）② 显示（构建中虚线/主副图指标入口）③ 调试（三常驻复制按钮）；每区有 `textSecondary` 小标题 + 分隔；统一输入/按钮/开关样式 |
| **十字线信息框** | 卡片化：左列标签 `textSecondary` 定宽，右列等宽数值 `textPrimary`；按来源（K0/K1/Kn/副图）加细分隔与左侧语义色条；圆角 8、描边 `border`、底色 `bgElevated` |
| **标题栏** | 设置按钮用 `accent` 描边/填充区分态；窗口三键统一为自定义细描边风格，与面板一致 |
| **空/错/加载态** | 空态：居中图标 + 说明 + 引导按钮；错误：顶部 snack 条样式（danger 左条）；加载：面板内骨架/居中 spinner + 文案 |
| **状态栏** | 底部细状态条显示 `步进 idx / 总数 / 当前层 Kn / 播放中`，替代散落在历史记录的调试信息外露 |

### 2.5 无障碍（WCAG AA）
- 移除 Windows `ExcludeSemantics` 或仅对纯装饰层排除；保留语义标签（按钮 `tooltip` 已有，补 `semanticsLabel`）。
- 文字/底色对比 ≥ 4.5:1（统一 `textPrimary` 在 `bgBase` 上达标）。
- 字号用 `sp` 随系统缩放；聚焦环统一 `accent` 2px。
- 触控目标 ≥ 44px（图标按钮从 36→40px，间距补足）。
