逐件对比：当前 → 优化后

指标芯片 当前

  • 整组默认 透明度 0.38，需 hover 才显形 → 可发现性差
  • 多项用 / 斜杠 挤一行，多选时难解析
  • 裸色 0xFFE2E8F0 散落，无层类型语义

指标芯片 优化后

  • 胶囊组：每项独立 pill，默认 0.9 可发现，hover 微抬升
  • 左侧 色点 对应层类型语义色（连线/中枢/买卖点）
  • 「＋ 指标」独立入口，双击 × 关闭单项

设置面板 当前

  • 控件 一长条平铺，无分组无层级
  • 表面色 0xF01A1A1A 与画布无梯度关系
  • 三常驻复制按钮与数据控件混排

设置面板 优化后

  • 三个分区：数据 / 显示 / 调试，各有小标题
  • 统一令牌表面梯度 + 统一输入/开关/按钮样式
  • 调试按钮归组，主操作（复制快照）用 accent 强调

十字线信息框 当前

  • 0xEE121212 半透明 + 1px 描边，无分区
  • 分隔用 = 铺满，略显粗糙
  • 标签/数值无来源语义区分

十字线信息框 优化后

  • 卡片化 + 圆角 8 + 描边 + 底色 bgElevated
  • 按来源（K线/K1/中枢/买卖点）左侧语义色条分区
  • 数值统一等宽字体，标签/值两列对齐
