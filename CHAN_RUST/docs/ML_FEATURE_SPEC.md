# ML 规格：K0 一类 BS（当前阶段·schema_version=1）

## 防泄漏纪律（2026-08-10）

| 风险 | 口径 |
|------|------|
| 未来函数 | α=发现后固定**展望窗**内判定；用当步 **live 一类帧** + **asOf 截断**连线极值；禁止跳末末态回标 |
| 测试窥探 | 测试评估成功后**锁定**；不可改切分/展望窗重跑（须退出 ML 再进） |
| 调参 | 仅验证集网格；测试只评估一次 |
| 漂移 | 报告训练/验证/测试标签√率 + 特征均值相对训练的 max\|z\| |

## 操作

1. 设训练/验证比例、展望窗 K（默认 64）。
2. 「加载」：逐K采特征并在窗到期打标 → 时序三截 → 验证调参 → 测试一次并锁定。
3. 看测试经验胜率、标签率、漂移告警。

## 切分默认

训练 60% / 验证 20% / 测试 20%（按样本 `x` 时序前→后）。

## 展望窗 α

- 到期：`asOf >= x + horizon`，或数据末截断。
- √：到期时 live 一类仍含该点，且在 `[lineX1, min(lineX2, asOf)]` 内为 Ba最低/Sa最高。
- 特征仍在发现步冻结（`featureFrozenAt=stepIdx`）。
