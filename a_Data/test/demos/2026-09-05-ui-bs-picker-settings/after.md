# 本次实现

## 现在长什么样

- 买点和卖点都用三角；买1/卖1 三角，买2/卖2 箭头，买3/卖3 再三角。买在蜡烛下、尖朝上；卖在蜡烛上、尖朝下。
- 策略条件只留一组「N类BS」：选买点或卖点，再填数字 N。1=一类，2=二类，3 及以上仍是原来的三类及以上。0 或 -1=该侧全部类号。旧策略里的一类买点还能用。
- 主图进了 K0，K 线只有一项时直接显示「K0」，点一下就勾选。合并、中枢、连线等同理；延伸、均线这种一项以上的仍进子菜单。
- 机器学习问号改到按钮左边，宽度与策略回测一致；复制调试信息等按钮同一宽度、同一高度。

## 怎么验

1. 002003 默认区间，连续单步，不要只靠一键走完。
2. 设置：机器学习问号在左，和策略回测一样宽。
3. 主图伸展钮 → K0 → 直接点「K0」应勾上 K0 线。
4. 策略回测条件：N类BS，N=1；跑出点后看三角/箭头。
