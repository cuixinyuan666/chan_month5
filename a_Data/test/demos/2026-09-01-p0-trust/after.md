# 本次实现

## 现在长什么样

- 一次性走完和一步一步点，副图必须同一套数：买卖点、中枢、分型判断、比例、斜率、节奏。
- 走完可以少画中间过程，但不能少算已冻住的连线。
- 走完、自动播放顶部有中文进度；走完可以取消，停在当前根，已经写下的点还在。
- 计算库对不上或找不到：中文停机，请覆盖本次那一份后再冷启动。
- 对外包默认关开发演示自动加载；研究时可在设置里打开。

## 怎么验收

1. 002003 默认区间，1 分钟先连续单步看副图，再重新加载后长按走完对同一根。
2. 分笔同样做一遍（根数更多，更能看出进度条）。
3. 不要用「一键走完」代替连续单步当唯一验收；走完只拿来和单步对拍。
4. 设置里「一键复制历史记录 / 查看历史记录 / 复制页面快照」三个按钮还在。
