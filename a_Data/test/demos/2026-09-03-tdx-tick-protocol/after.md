# 本次实现

## 现在长什么样

- 普通股票的分笔从通达信行情口取（带笔数的那条指令），不再把本地导出 txt 当权威。
- 日线及更长周期仍是：分笔先合成 1 分钟，再升周期。
- 没有笔数就记 0，不再填 1。
- 区间里有 0 笔数，或缺主动买/主动卖/中性时，会弹窗问要不要继续用筹码分布、笔数分布、峰线和副图 Kn 笔数。
- 点「不继续」：K 线和缠论仍加载；只是本会话关掉这些图，不改你保存的设置。
- test 股和自定义 OHLC 仍读文件。

## 怎么验收

1. 002003 默认区间冷启动：应弹出笔数为 0 的询问。点「不继续」后 K 线还在，筹码/笔数图本会话关掉。
2. 再加载同一区间点「继续用」：这些图按设置仍可开，只是很多笔数是 0。
3. 把日期改到 2018-01-10 当天再加载：不应再弹笔数为 0。
4. 改成日线再加载：仍能出日 K。
5. 切到 test：不连行情口。
6. 设置里历史记录三个按钮还在。连续单步，不要只用一键走完。
